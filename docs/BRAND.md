# NEW brand guide

Built from the client logo. The original artwork is kept in `prototype/assets/client-logo-original.jpg`. The refined vector logo is generated by `scripts/build-logo.py`, so the geometry can be tuned and rebuilt.

## Logo

| Asset | File | Use |
| --- | --- | --- |
| Full logo (blades and NEW wordmark) | `prototype/assets/new-logo.svg` | Splash, login, documents, store listing |
| Mark (blades only) | `prototype/assets/new-mark.svg` | App icon, favicon, small headers, watermark |
| Wordmark | `prototype/assets/new-wordmark.svg` | Wide spaces where the mark is shown separately |
| In code | `AC.logo.full(size)`, `AC.logo.mark(size)`, `AC.logo.tile(size, full)` | Prototype apps |

What changed from the client artwork: the same six blades (traced from the client artwork with scripts/trace-logo.py), the same order (blue, red, green, blue, red, green, clockwise from the top) and the same three colours, redrawn with clean vector curves, even spacing and sharp tips. The wordmark is converted to outlines in a tight bold grotesque so it renders the same everywhere with no font file.

Rules
- Minimum size: 16 px for the mark, 40 px for the full logo.
- Clear space: at least the height of one blade on every side.
- On dark or blue backgrounds, place the logo on a white rounded tile (`AC.logo.tile`). Do not recolour the blades.
- Do not stretch, rotate, outline, add shadows to the artwork or put it on busy images.
- No gradients, in the logo or anywhere in the product.

## Colour

Sampled from the client logo: blue `#2E3192`, red `#ED1B24`, green `#00A74F`.

| Role | Token | Value | Share |
| --- | --- | --- | --- |
| Neutrals: canvas, surfaces, lines, text | `--bg`, `--surface`, `--line`, `--ink` | `#F5F6FA`, `#FFFFFF`, `#E3E6F0`, `#101426` | 60% |
| Primary: navigation, headers, primary actions | `--brand`, `--brand-d`, `--deep`, `--brand-l` | `#2E3192`, `#1F2270`, `#151858`, `#E9EAF7` | 30% |
| Accent red: promotions, alerts, unread, destructive | `--red` | `#ED1B24` (text `#D8151D`) | 5% |
| Accent green: success, live, vendors, savings | `--green` | `#00A74F` (text `#00873F`) | 5% |
| Warning only | `--warn` | `#9A5B00` on `#FCF0DA` | rare |

Use red and green sparingly. If a screen has more than a few red or green elements, remove some. Text colours for red and green are slightly darker than the logo colours so they pass contrast on white.

## Glossy finish without gradients

Gloss is made from flat layers: a bright inner top edge, a soft coloured shadow, a translucent flat sheen shape on header bands, and glass blur on the tab bar, top bar and toasts. See `prototype/shared/theme.css`. Do not use gradients.

## Flutter

Mirror `base.css` tokens and `theme.css` in a shared `ThemeData` in the design package. Build the logo from the SVG files with `flutter_svg`, and generate the Android launcher icon from `new-mark.svg` on a white adaptive icon background.
