# Payment logos

Drop the official files here. They are picked up automatically, no code change:

- `bkash.svg` (or `bkash.png`)
- `nagad.svg` (or `nagad.png`)

Use the files from each provider's merchant or brand kit, with their usage rules. SVG is best. A horizontal logo with a transparent or white background works; the tile is 64 x 40 px and the image is scaled to fit with 5 px padding. Until a file exists, a coloured letter tile is shown instead.

Do not use copies from logo download sites. They can be out of date and are often not licensed for commercial use.

## Current files

`bkash.svg` and `nagad.svg` are placeholders taken from a public logo site (logotyp.us), used so the demo is recognisable. Replace them with the official files from the bKash and Nagad merchant kits before launch. Keep the same file names.
